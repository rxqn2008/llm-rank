# CodeBuddy NPC

A Cloud Agent on the CNB platform — your AI teammate for autonomous development tasks.

## Features

- **Autonomous Requirement Delivery** - Understands requirements, analyzes code, implements solutions, and submits PRs
- **Parallel Task Processing** - Assign multiple tasks simultaneously; multiple NPCs run in parallel without interference
- **Intelligent Context Acquisition** - Deeply integrated with CNB repositories, Issues, and pipelines — autonomously understands requirements and analyzes code
- **Build Failure Auto-Fix** - Automatically takes over on build failures, analyzes logs, and fixes issues until pipelines pass
- **Merge Conflict Smart Resolution** - Understands code change intentions and provides reasonable merge solutions
- **Multi-NPC Team Collaboration** - Multiple NPCs collaborate by role: development, code review, progress management
- **Team Engineering Standards** - Customize NPC roles, SOPs, and Skills on demand

## Usage

Comment in an Issue or PR:

```
@CodeBuddy <your request>
```
