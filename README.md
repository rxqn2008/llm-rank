# CodeBuddy NPC

## 什么是 CodeBuddy NPC

CodeBuddy NPC 是运行在 CNB 平台上的 Cloud Agent，你研发流程中的 **AI 员工**。

你只需明确预期，NPC 云端自主闭环开发任务「需求理解 → 上下文获取 → 分支创建 → 编码实现 → PR 提交」，最后邀请你验收成果。

### 与本地 AI 助手对比

| 维度 | 本地 AI 助手 | CodeBuddy NPC |
| :--- | :--- | :----------- |
| **协作模式** | 结对编程 | `@NPC` 即可派活，云端异步执行，多任务并行 |
| **驱动方式** | 人工输入上下文 + 规约文档 | 自主获取需求背景与工程代码 |
| **上下文记忆** | 受限于上下文窗口 | 关键决策持久化于仓库 |
| **协作边界** | 个人提效工具 | 融入研发流程，团队的 AI 成员 |

### 核心优势

- **目标驱动**：你定义"要什么"，NPC 负责"怎么做"。从需求到 PR，全程自主闭环。
- **并行任务处理**：支持同时派发多个任务，多个 NPC 云端并行推进，互不干扰。
- **上下文智能获取**：深度融合 CNB 仓库、Issue、流水线，自主理解需求、分析代码、排查问题。
- **团队工程规范沉淀**：按需定制 NPC 职能、SOP 与 Skills，将工程规范转化为可复用的 AI 能力。


## 快速开始

无需克隆、无需配置。在 **你自己的 CNB 仓库** 中，**新建一个 Issue 并 `@npc/CodeBuddy`**，即可把任务派发给 NPC 自主处理。

> 💡 体验步骤非常简单：打开你任意仓库的 Issue 页面，输入 `@npc/CodeBuddy` 加上你的需求，剩下的交给 NPC。

### 三步体验

1. **进入你自己的仓库 → 新建 Issue**
   > 任意仓库都可以，无需在当前仓库操作。
2. **在 Issue 内容中 `@npc/CodeBuddy`**，清晰描述你的需求（描述越具体，NPC 执行越精准）
3. **NPC 接单，开始干活**：NPC 将自动获取上下文、制定方案、编码实现、提交 PR，完成后在 Issue 中通知你验收


## 典型场景

| 场景 | 说明 |
| :--- | :--- |
| **NPC 给你做需求** | NPC 自主理解需求、分析代码、编码实现、提交 PR，等你验收 |
| **构建失败自动修复** | 深度集成 CNB 流水线，构建失败时自动接手，分析日志、修复问题，直至通过门禁 |
| **合并冲突智能解决** | 理解代码变更意图，提供合理的合并方案，解决分支冲突 |
| **多 NPC 团队协作** | 多个 NPC 按职能分工协作：功能开发、代码评审、进度管理，实现企业级工程实践 |


## 支持模型

- `deepseek-v4-pro`
- `deepseek-v4-flash`
- `hy3`
