# CodeBuddy NPC

CodeBuddy 是一个运行在云端的喜欢干活的 NPC，开干吧各位。

## 功能特性

- 多 AI 模型支持（GLM、Hy3、DeepSeek）
- 自动处理 Issue 和 Pull Request 评论
- 自定义 NPC 角色和头像

## 支持的 AI 模型

- deepseek-v4-pro
- deepseek-v4-flash
- glm-5.2
- glm-5.1
- glm-5.0-turbo
- hy3-preview

## 配置文件

- `.cnb.yml` - NPC 行为
- `.cnb/settings.yml` - NPC 角色
